## 一、先搞懂三个词：文件、程序、路径

**文件**：电脑里存东西的基本单位。一张照片、一首歌、一份 Word、一个安装包，都是文件。

**程序（软件）**：能运行起来、干活的文件集合。微信、浏览器、Word 都是程序。程序通常由很多文件组成，放在一个文件夹里。

**文件夹**：装文件的盒子。文件夹里还能再放文件夹，这就是"子文件夹"。

**路径**：说明一个文件"住在哪"的完整地址。例如：

```
C:\Users\huang\Desktop\报告.docx
```

从右往左读：

- `报告.docx`：文件名
- `Desktop`：它在"桌面"这个文件夹里
- `huang`：桌面属于用户 huang
- `Users`：用户文件夹
- `C:\`：C 盘根目录

> 记住一句话：**桌面不是"一个地方"，它只是 C 盘里的一个文件夹。** 所以桌面塞满文件，等于 C 盘塞满文件。

**C 盘、D 盘是什么？**
硬盘被切成几个"分区"，分别叫 C、D、E。C 盘通常装系统，D 盘适合放自己的资料。软件默认装 C 盘没问题，但**个人文件（照片、视频、下载）建议放 D 盘**，重装系统时不容易一起没了。

## 二、文件扩展名：电脑认后缀，不认图标

文件名最后那个点后面的部分，叫**扩展名**，它决定电脑用什么方式打开这个文件。

| 扩展名 | 是什么 | 用什么打开 |
| --- | --- | --- |
| `.docx` / `.doc` | Word 文档 | Word、WPS |
| `.xlsx` / `.xls` | Excel 表格 | Excel、WPS |
| `.pptx` / `.ppt` | 演示文稿 | PowerPoint、WPS |
| `.pdf` | 固定版式文档 | 浏览器、PDF 阅读器 |
| `.txt` | 纯文本 | 记事本 |
| `.jpg` / `.png` | 图片 | 看图软件 |
| `.mp4` / `.mov` | 视频 | 播放器 |
| `.mp3` | 音频 | 播放器 |
| `.zip` / `.rar` / `.7z` | 压缩包 | 解压软件 |
| `.exe` | Windows 安装包或程序 | 双击运行 |
| `.msi` | Windows 安装包 | 双击运行 |
| `.dmg` | macOS 安装镜像 | 双击打开 |
| `.apk` | 安卓安装包 | 手机上安装 |

### 为什么"看不到后缀"很危险

Windows 默认隐藏已知文件类型的扩展名。骗子会把病毒命名成：

```
你的照片.jpg.exe
```

因为隐藏了 `.exe`，你只看到 `你的照片.jpg`，以为是一张图，双击就运行了程序。

**建议打开扩展名显示：**

- Windows 11：文件资源管理器 → 顶部"查看" → "显示" → 勾选"文件扩展名"
- Windows 10：文件资源管理器 → "查看"选项卡 → 勾选"文件扩展名"
- macOS：访达 → 设置 → 高级 → 勾选"显示所有文件扩展名"

### 改后缀不能改文件类型

把 `照片.jpg` 重命名成 `照片.png`，它还是 JPG，只是名字变了，有些软件反而打不开。**扩展名是标签，不是转换器。** 要转格式得用专门的转换工具。

## 三、压缩包与解压

### 压缩包是什么

压缩包像一个"行李箱"：把很多文件塞进去，体积变小，方便传输。常见格式：

- `.zip`：最通用，Windows 和 macOS 都能直接打开
- `.rar`：压缩率高，需要专门软件
- `.7z`：压缩率高，需要 7-Zip 等软件

**压缩**是把文件装进行李箱；**解压**是把行李箱打开，把文件拿出来。**你不能直接在行李箱里改衣服。**

### 正确解压步骤（Windows）

1. 找到压缩包，**先看它是不是真的压缩包**（确认后缀是 `.zip` / `.rar` / `.7z`）。
2. 右键点击压缩包。
3. 选择"解压到当前文件夹"或"解压到 xxx\"。
4. 等进度条走完，得到一个新文件夹。
5. 进入新文件夹，再打开里面的文件。

推荐安装 **[7-Zip](https://www.7-zip.org/)**（免费开源）或 **[Bandizip](https://www.bandisoft.com/bandizip/)**（免费版够用）。**[WinRAR](https://www.win-rar.com/download.html)** 也能用，但免费版会弹广告。

> 更稳妥的做法：右键 → "解压到 <文件名>\"，它会自动建一个同名文件夹，不会把几十个文件撒得满桌面都是。

### macOS

双击 `.zip` 就会自动解压到旁边。`.rar` / `.7z` 需要安装 **[Keka](https://www.keka.io/zh-cn/)** 或 **[The Unarchiver](https://theunarchiver.com/)**。

### 手机

- iPhone："文件"App 里点开压缩包，会自动解压出一个文件夹。
- 安卓：自带"文件管理"通常支持 zip；rar/7z 可装 **[ZArchiver](https://zarchiver.org/)**。

### 解压时的六个坑

**坑 1：在压缩包里直接双击文件。**
你只是"预览"了其中一个文件，改完可能没保存回去。正确做法是先解压，再编辑。

**坑 2：解压出一堆散文件。**
选择"解压到同名文件夹"，而不是"解压到当前目录"。

**坑 3：中文文件名乱码。**
老压缩包常用 GBK 编码，Windows 可能识别成乱码。用 Bandizip 打开，在"代码页"里选"简体中文（GBK）"再解压。

**坑 4：分卷压缩包只下了一部分。**
看到 `xxx.part1.rar`、`xxx.part2.rar`，必须**全部下载放在同一个文件夹**，然后只解压 part1，它会自动找其他卷。

**坑 5：解压需要密码。**
密码通常在资源发布页、邮件正文或卖家留言里，不是压缩包坏了。别去下"破解工具"，多半是病毒。

**坑 6：压缩包里的 `.exe` 直接双击。**
尤其是"学习资料""破解版""绿色版"，里面常是捆绑安装器。先解压，看清里面有什么，再决定。

### 压缩包本身也可能是陷阱

如果收到陌生人发来的压缩包，里面是 `.exe`、`.bat`、`.scr`、`.js`，**不要运行**。正常文档、图片、视频不需要你"先运行一个程序才能看"。

## 四、下载：从哪里下，比下什么更重要

### 优先顺序

1. **软件官网**（最安全）
2. **系统自带应用商店**（Microsoft Store / App Store）
3. **知名开源平台**（GitHub Releases 等）
4. 大型下载站（要非常小心"高速下载器"）

### 下载站的三类陷阱

- **"高速下载"按钮**：通常是广告，下下来的是下载器，安装时会塞一堆软件。
- **多个"立即下载"按钮**：真正的下载链接往往在最下面，字最小、最不起眼。
- **文件名带"@安装""绿色版""破解版"**：捆绑和病毒高发区。

> 判断方法：把鼠标悬停在按钮上，看浏览器左下角显示的真实链接。官网域名应该和软件名对得上。
>
> 本手册提到的软件，官网地址统一整理在[附录一](#附录一常用软件官网汇总)，不用自己搜。

### 下载后去哪找

- Windows：`C:\Users\你的用户名\Downloads`（下载文件夹）
- macOS：`下载` 文件夹
- 手机：浏览器的"下载"记录

建议每月清一次下载文件夹。**安装包用完就可以删**，留着也不会让软件运行得更好。

### 关于"文件大小"

一个 Word 文档几 MB，一张手机照片几 MB，一首歌 5–10 MB，一部高清电影 1–5 GB，一个大型游戏几十 GB。如果下载的"电影"只有 200 KB，那基本是假的。

## 五、安装软件：一路"下一步"是最危险的

### Windows 安装包

常见两种：`.exe` 和 `.msi`。双击后会出现安装向导。

**安装时必做的三件事：**

1. **选"自定义安装"**，不要选"快速安装 / 一键安装"。
2. **逐页看勾选项**，取消"安装某某浏览器""推荐某某管家""设为首页"等。
3. **改安装路径**（可选）：把 `C:\Program Files\...` 改成 `D:\Programs\...`。路径里**不要有中文和空格**，避免个别软件出错。

**安装完成后：**
取消勾选"立即体验""打开某某"，避免一装完就弹一堆窗口。

### 便携版 / 绿色版

- **便携版（Portable）**：解压即用，不写注册表，可以放 U 盘。相对干净。
- **"绿色版"**：这个词没有标准，谁都能叫。很多所谓绿色版其实带捆绑，甚至被改过。**来源不明就不要用。**

### macOS

- `.dmg`：双击挂载，把图标拖进"应用程序"文件夹。
- `.pkg`：双击按提示安装。
- 首次打开提示"无法验证开发者"：到"系统设置 → 隐私与安全性"里点"仍要打开"。**只对你确认过来源的软件这么做。**

### 手机

- iPhone：只从 App Store 装。企业签名、描述文件安装有风险。
- 安卓：优先应用商店；装 `.apk` 时，系统会要求"允许安装未知应用"，装完建议关掉这个权限。

### 安装位置与权限

- 不要装到 `C:\Windows`、`C:\Program Files` 里面手动新建乱七八糟的文件夹。
- 安装时如果弹出"用户账户控制"（UAC），先看清程序名，再点"是"。**不认识就点"否"。**

## 六、卸载软件：删图标不叫卸载

### 最常见的错误

把桌面图标拖进回收站，或者右键"删除"文件夹。结果：

- 软件还在，占着几个 GB；
- 开机还在后台启动；
- 注册表、服务、计划任务都还在；
- 下次装同名软件可能冲突。

**删除图标 = 拿掉了门牌；卸载 = 把房子拆了。**

### Windows 正确卸载

**方法一（推荐，Windows 11）：**
设置 → 应用 → 已安装的应用 → 找到软件 → 右侧"..." → 卸载。

**方法二（Windows 10）：**
设置 → 应用 → 应用和功能 → 点击软件 → 卸载。

**方法三（老软件）：**
控制面板 → 程序和功能 → 右键 → 卸载。

**方法四（自带卸载器）：**
开始菜单里找到该软件的文件夹，里面常有 `Uninstall.exe`。

卸载后如果提示重启，就重启。有些文件正被占用，重启后才会真正删掉。

### macOS 正确卸载

1. 打开"访达 → 应用程序"。
2. 把软件拖进废纸篓。
3. 清倒废纸篓。
4. 部分软件自带卸载器（如 Adobe、Office），优先用它。

残留的配置文件在 `~/Library/Application Support/`、`~/Library/Preferences/`。**不确定是什么就不要删**，删错可能影响其他软件。

### 手机卸载

- iPhone：长按图标 → "移除 App" → "删除 App"。注意"从主屏幕移除"只是藏起来，不是卸载。
- 安卓：长按图标 → 应用信息 → 卸载；或设置 → 应用管理 → 卸载。

### 卸载不干净怎么办

- 优先用软件**自带的卸载程序**。
- 其次用系统卸载入口。
- 最后才考虑 **[Geek Uninstaller](https://geekuninstaller.com/)** 这类专用工具（免费版够用）。
- **不要手动删 `C:\Program Files` 和注册表**，除非你明确知道自己在删什么。省下的几百 MB，可能换来系统故障。

### 卸载前要保留什么

- 聊天记录（微信/QQ 的聊天记录默认不在程序目录，但重装前最好备份）
- 软件内的项目文件、导出文件
- 许可证、激活码
- 浏览器书签与密码（登录账号同步即可）

## 七、浏览器：地址栏、标签页与假下载按钮

### 用哪个浏览器

任选一个即可，不必全装。国内网络环境下，建议至少保留 Edge 或 Chrome 其中之一。

| 浏览器 | 官网 | 说明 |
| --- | --- | --- |
| Microsoft Edge | <https://www.microsoft.com/edge> | Windows 自带，Chromium 内核，可直接装 Chrome 扩展 |
| Google Chrome | <https://www.google.com/chrome/> | 扩展生态最全；部分在线服务在境内访问可能较慢 |
| Mozilla Firefox | <https://www.mozilla.org/firefox/> | 开源，隐私保护较好，内核与 Chrome 不同 |

### 地址栏不是搜索框（但它也能搜索）

在地址栏输入：

- `qq.com` → 直接访问腾讯官网
- `如何解压文件` → 交给搜索引擎

**区别在于有没有"域名"的样子。** 想访问某个网站，就输入它的域名；想问问题，就输入问题。

### 看清域名

`https://www.example.com/login`

- `https`：加密传输（小锁图标）。**有锁不等于网站可信**，骗子也能申请证书。
- `www.example.com`：真正的域名。看**最后一个点和它前面那段**。
- `/login`：网站内的页面路径。

警惕：`example.com.cn` 和 `example.cn` 是两个不同网站；`paypa1.com`（数字 1）不是 PayPal。

### 标签页

- `Ctrl + T`：新标签页
- `Ctrl + W`：关闭当前标签页
- `Ctrl + Shift + T`：恢复刚关掉的标签页（救命键）
- `Ctrl + Tab`：切换到下一个标签页

标签页开太多会占内存。电脑卡的时候，先关掉几十个标签页试试。

### 下载与"假按钮"

网页上闪烁的"立即下载""高速下载""点击安装"，很多是广告。真正的下载链接通常：

- 在页面底部或正文里；
- 文字朴素，比如"下载 Windows 版"；
- 鼠标悬停后显示的域名与官网一致。

**浏览器提示"此文件可能有害"时，不要直接点"保留"。** 先想想来源。

### 缓存与 Cookie

- **缓存**：网页的临时副本，用来加速。页面样式错乱时可以清。
- **Cookie**：网站存在你浏览器里的小纸条，用来记住登录状态。
- 清理位置：`Ctrl + Shift + Delete`（Chrome/Edge）。

清缓存不会删你的收藏和账号，但可能让所有网站退出登录。

### 扩展（插件）

只装必要的。来历不明的扩展能读取你所有网页内容，包括密码。装之前看开发者、下载量和评价。

## 八、账号与密码

### 三个基本原则

1. **一个网站一个密码。** 撞库攻击就是拿 A 站泄露的密码去试 B 站。
2. **重要账号开两步验证（2FA）。** 密码 + 手机验证码/身份验证器，安全性提升一个量级。
3. **验证码不给任何人。** 客服、公安、快递、银行，都不会问你要验证码。

### 密码怎么记

- 用**密码管理器**（**[Bitwarden](https://bitwarden.com/download/)** 免费开源、**[1Password](https://1password.com/downloads/)** 付费、浏览器自带也可以）。
- 或者用**一句话规则**：`平台名 + 固定短语 + 数字符号`，例如 `Taobao-吃了吗-2026!`。不同平台换平台名。
- 不要用：生日、手机号、`123456`、`qwerty`、`password`、姓名拼音。

### 两步验证优先用"身份验证器"

短信验证码可能被拦截或补卡攻击。**[Google Authenticator](https://support.google.com/accounts/answer/1066447)**、**[Microsoft Authenticator](https://www.microsoft.com/zh-cn/security/mobile-authenticator-app)**、微信/支付宝里的验证器都行。**记得保存恢复码。**

### 公共电脑

- 用完退出账号，别勾"记住我"。
- 用无痕模式只能减少本地记录，**不能防止键盘记录器**。
- 不要在公共电脑上登录网银、公司邮箱。

## 九、文件管理：命名、分类与备份

### 命名

推荐格式：

```
2026-11-24_项目名_版本.docx
```

好处：按时间排序自然，搜索容易，发给人不会重名。

避免：

- `新建文件夹 (3)`、`最终版`、`最终版2`、`真最终版`
- 文件名里带 `\ / : * ? " < > |`（Windows 不允许）
- 超长文件名、纯符号文件名

### 分类

不用追求完美体系。三层足够：

```
D:\
├─ 工作
│  ├─ 2026
│  └─ 模板
├─ 个人
│  ├─ 照片
│  └─ 证件扫描
└─ 下载（临时区，定期清）
```

**桌面只放正在处理的东西**，处理完归档。桌面堆满会让开机变慢（尤其是机械硬盘），也容易误删。

### 备份：3-2-1 原则

- **3** 份数据
- **2** 种不同介质（电脑 + 移动硬盘 / 云盘）
- **1** 份放在异地（云盘或另一个城市）

对普通人简化版：

1. 重要文件放电脑 D 盘；
2. 同时同步到云盘（[OneDrive](https://www.microsoft.com/microsoft-365/onedrive) / [百度网盘](https://pan.baidu.com/) / [阿里云盘](https://www.alipan.com/) / [iCloud](https://www.icloud.com/)）；
3. 每半年拷一份到移动硬盘。

** RAID 不是备份，同步盘也不是备份。** 误删会同步删除， ransomware 加密也会同步加密。要有"历史版本"或离线副本。

### U 盘与移动硬盘

- 拔出前点"安全弹出"（Windows 右下角 U 盘图标）。直接拔可能损坏文件系统。
- U 盘不要长期插着当仓库，闪存颗粒有寿命。
- 来历不明的 U 盘**不要插**，可能带自动运行的恶意程序。

## 十、安全常识：骗子利用的是"着急"

### 常见套路

| 套路 | 话术 | 应对 |
| --- | --- | --- |
| 冒充客服 | "你的快递丢了，给你理赔" | 挂断，从官方 App 查订单 |
| 冒充公检法 | "你涉嫌洗钱，需要配合调查" | 挂断，打 110 核实 |
| 冒充领导/熟人 | "我在开会，帮我转笔钱" | 电话/视频核实 |
| 刷单返利 | "动动手指日入三百" | 直接拉黑，100% 诈骗 |
| 虚假投资 | "内部渠道，稳赚不赔" | 不碰，别下陌生 App |
| 屏幕共享 | "我教你怎么操作，你共享一下屏幕" | 拒绝，共享屏幕=把密码给人看 |
| 钓鱼短信 | "ETC 失效/医保停用，点击认证" | 不点链接，去官方 App |

### 几条硬规则

1. **任何要求你"转账到安全账户"的，都是诈骗。** 没有安全账户这种东西。
2. **任何要求你"共享屏幕"的客服，都是骗子。**
3. **任何让你"下载会议软件并加入会议"的办案人员，都是骗子。**
4. **任何催你"马上、立刻、否则"的，先停下来。** 紧急感是骗术的核心。
5. **验证码、银行卡密码、身份证照片，不给任何人。**

### 病毒与杀毒

- Windows 自带 **Microsoft Defender**，日常够用。**不要装多个杀毒软件**，会互相打架。
- macOS 也有内置防护，别从不明来源下载"清理大师""加速器"。
- 手机不要装"手机管家""电池修复"类来路不明的 App。
- 系统更新及时装。更新里很大一部分是安全补丁。

### 远程控制

[TeamViewer](https://www.teamviewer.com/)、[向日葵](https://sunlogin.oray.com/)、[AnyDesk](https://anydesk.com/) 本身是正规工具，但**骗子最爱用**。任何人让你装远程软件并报出连接码，先假设是诈骗。除非是你主动求助、且对方身份明确。

## 十一、电脑出问题时的自查顺序

### 通用四步

1. **重启。** 不是关机再开机，是"重启"。能解决一半以上的临时故障。
2. **看错误信息。** 把原话记下来（拍照也行），再搜索。不要只搜"电脑坏了"。
3. **回想最近改了什么。** 装了新软件？更新了驱动？插了新设备？删了文件？八成和它有关。
4. **最小化排查。** 没网就先试另一台设备；没声音就先换耳机；黑屏就先检查电源和线。

### 常见问题

**连不上 Wi-Fi**
- 手机能连、电脑不能 → 电脑的 Wi-Fi 开关/驱动问题。
- 都不能连 → 路由器问题，重启路由器（拔电 30 秒）。
- 提示"无法获取 IP" → 重启路由器，或忘记网络重连。

**电脑很卡**
- 打开任务管理器（`Ctrl + Shift + Esc`），看 CPU、内存、磁盘谁占满。
- 磁盘 100%：可能是 Windows 更新或杀毒扫描，等它跑完；机械硬盘老化也会这样。
- 开机启动项太多：任务管理器 → 启动 → 禁用不需要的。

**C 盘满了**
- 设置 → 系统 → 存储 → 清理建议。
- 微信/QQ 的聊天文件是大头，在软件设置里把存储位置改到 D 盘。
- 别乱删 `C:\Windows` 和 `Program Files`。用系统自带清理最安全。

**蓝屏**
- 拍照记下错误代码（如 `CRITICAL_PROCESS_DIED`）。
- 偶尔一次不用管；频繁出现再查驱动、内存、硬盘。

**打印机不能打**
- 看是不是默认打印机变了；
- 看队列里是不是卡着旧任务；
- 重启打印服务（`services.msc` → Print Spooler → 重启）；
- 重装官方驱动。

**文件打不开**
- 看扩展名，装对应软件；
- 提示"文件已损坏"：重新下载，注意是不是没下载完；
- 提示"被占用"：关掉可能打开它的程序，或重启。

### 找人帮忙时，提供这些信息

- 什么设备、什么系统（Windows 10/11、macOS 版本、手机型号）
- 你想做什么
- 你点了什么
- 出现了什么（截图/照片）
- 你已经试过什么

**截图**：`Win + Shift + S`（Windows 区域截图）、`Cmd + Shift + 4`（macOS）。比拍屏幕清楚得多。

## 十二、值得记住的快捷键与小技巧

### Windows

| `F2` | 重命名 |

### macOS

| 快捷键 | 作用 |
| --- | --- |
| `Cmd + C / V / X` | 复制 / 粘贴 / 剪切 |
| `Cmd + Z` | 撤销 |
| `Cmd + S` | 保存 |
| `Cmd + F` | 查找 |

### 通用小技巧

- **双击标题栏**可以最大化窗口。
- **拖动文件到另一个文件夹**是移动；按住 `Ctrl` 拖是复制。
- **回收站不是保险箱**，清空就没了。重要文件别只放桌面。
- **浏览器 `Ctrl + Shift + T`** 能找回刚关掉的页面。
- **微信电脑版的文件**默认存在 `C:\Users\...\Documents\WeChat Files`，占空间很大，可在设置里改路径。
- **PDF 要编辑**，先确认是扫描件还是电子版。扫描件需要 OCR，普通 PDF 可以用 Word 或 PDF 工具打开。
- **"清理大师"类软件**大多没必要，Windows 自带磁盘清理足够。

## 附录二：新手十条铁律

1. **看不懂的弹窗，先点"取消"或直接关掉，不要点"确定"。**
2. **安装软件走"自定义"，逐页取消勾选。**
3. **卸载去系统设置，不要只删图标。**
4. **下载只认官网，不点"高速下载"。**
5. **陌生压缩包里的 `.exe` 不运行。**
6. **一个网站一个密码，重要账号开两步验证。**
7. **验证码、密码、屏幕共享，不给任何人。**
8. **重要文件至少存两份，一份在云端。**
9. **出问题先重启，再看错误原话，再搜索。**
10. **任何催你立刻转账、立刻操作的人，先挂断。**
